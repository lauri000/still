# Still 0.1.0

First Android release of Still, a native PDF speed reader.

- Import PDFs and choose a starting page using the original page preview.
- Read a centered word with nearby text, adjustable speed, and optional natural pauses.
- Hold the bottom-right corner to read; release to pause. Move right or left while holding to increase or decrease the current speed, without a play button or slider.
- Optionally align and highlight a focus letter while reading.
- Swipe the text or tap a nearby word to select where to resume. Text navigation stays separate from the corner's speed gesture.
- Preserve pages, PDF bookmark chapters, corrections, and reading progress.
- Export and import portable book backups compatible with the iPad/macOS app.
- Keep reading offline, with no account or network permission.

Requires Android 9 or newer. The universal APK includes ARM64, ARMv7, and x86 libraries.
PDFs need selectable text; OCR and automatic synchronization are not included.

This is the first build signed with Still's dedicated release key. If you installed
the earlier debug APK, export your book backups before uninstalling that build,
then install the release and import the backups.

The APK, SHA256SUMS, source commit manifest, and public signing certificate are
attached to this release. Verify the APK before installation with `shasum -a 256 -c SHA256SUMS`.
