# Still 0.1.15

Books now prepare their reading data once during PDF conversion, making Continue reading much faster.

- Saves final text, word indexes, and heading matches so opening a book does not repeat text processing.
- Keeps the original PDF and adds **Reprocess book** to regenerate reading data when the conversion pipeline changes.
- Preserves manual text corrections, page choices, custom chapters, and reading progress when reprocessing. Undo reprocessing is available in the current session.
- Uses the same versioned, portable book format on Android and Apple platforms.

**After updating:** Existing books need one explicit **Reprocess book** before reading. Open the book and use that button; future opens reuse the prepared data. New backups use book format version 2 and require this version of Still or newer.

On the 302-page Hume test PDF, Continue reading improved from 0.99–1.58 seconds to 0.12–0.18 seconds in the Android emulator. Results depend on the book and device.

Verified with 46 Android unit tests, the Android emulator suite and reprocessing checks, 72 Apple unit/layout tests, all 12 iPhone UI scenarios, cross-platform book-format contracts, and a macOS build. The signed Android release also passes release lint and 16 KB alignment checks.

Requires Android 9 or newer. Version code: 16. Signed with the existing release key; updating preserves books, positions, and settings.
