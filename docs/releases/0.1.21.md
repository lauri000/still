# Still 0.1.21

- Open books directly in the reader at your saved position, without the intermediate preview page.
- Go straight into reading after importing a file or downloading a Project Gutenberg book. Closing the reader returns to Books.
- Find editing, chapters, starting-word selection, book details, reprocessing, undo, backups, and deletion in each book’s … menu in the library.
- Keep original PDF comparison available in the text editor, and offer preparation when opening an older book that needs it.
- Fix a loading spinner that could remain visible when a PDF has no chapters.

Verified with Android and Apple unit tests, Android reader and navigation scenarios, iPhone and iPad UI tests, Android lint, and a macOS build. Physical-device testing remains outstanding.

Requires Android 9 or newer. Android package: `com.stillreader.app`, version code **22**. Signed with the existing Still release key so it updates earlier release installations while preserving books, positions, and settings.

The APK, SHA256SUMS, source commit manifest, and public signing certificate are attached to this release.
