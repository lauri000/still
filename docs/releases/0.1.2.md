# Still 0.1.2

Read with surrounding text arranged in rows around a fixed center word.

- Switch between the single-line reader and the expanded passage using the text icon. Only one view is shown at a time.
- Keep the active word, or its optional focus letter, centered while earlier rows appear above and later rows below.
- Tap a word in any visible row or swipe the text to choose where to resume. Hold-to-read and relative speed control work in both views.
- Keep your current word and reading speed when switching views.
- Show surrounding rows in short landscape windows with a compact passage layout.

Requires Android 9 or newer. This universal APK includes ARM64, ARMv7, x86, and x86_64 libraries.
Version code: 3. Signed with the same Android release key as previous releases;
updating preserves your books, reading positions, and settings.

The APK, SHA256SUMS, source commit manifest, and public signing certificate are
attached to this release. Download all four assets into one directory and run
`shasum -a 256 -c SHA256SUMS` to verify their checksums.
