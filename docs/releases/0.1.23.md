# Still 0.1.23

- Fix words joined by em dashes in single-line reading, including Moby-Dick passages such as `Usher—threadbare` and `there—there—thar`.
- Keep the dash with the preceding word and retain the existing natural pause. Preserve ordinary hyphenated words, apostrophes, and en-dash numeric ranges.
- Keep the original spacing in scrolling view and preserve chapter headings and navigation.
- Automatically update saved word indexes for already-imported books when the library opens. No re-download, re-import, or manual reprocessing is needed for books prepared by 0.1.22. Original files, text corrections, review choices, chapter anchors, and saved reading positions are retained. Older portable backups receive the same compatible index update on import.

Verified by reopening a complete Gutenberg Moby-Dick library saved by 0.1.22: all 976 joined-word em-dash tokens are corrected on Android and Apple, with identical native word indexes and unchanged source text, original EPUB bytes, chapters, and resume position. A second reopen retains the updated indexes.

Validation: 80 Android unit tests (3 optional corpus tests skipped), 103 Apple unit/integration tests (2 optional corpus tests skipped), four Android device regressions including an existing-library upgrade, two iPhone reader/navigation UI regressions, native prepared-reader compatibility checks, eight release-tool tests, and a macOS build. The release build also runs Android unit tests and release lint. Physical-device testing remains outstanding.

Built and published from `main`. Requires Android 9 or newer. Android package: `com.stillreader.app`, version code **24**. Signed with the existing Still release key so it updates earlier release installations while preserving the library and settings.

The APK, SHA256SUMS, source commit manifest, and public signing certificate are attached to this release.
