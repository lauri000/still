# Still 0.1.14

Maintenance release that simplifies the reader internals while preserving the existing reading experience and book format.

- Removes obsolete multiline layout and animation code from the single-line renderer.
- Consolidates import and text-repair progress, cancellation, and save handling.
- Retains manual passage scrolling, exact-word taps, reading options, contents navigation, and saved positions.

Verified with 39 Android unit tests and 29 emulator scenarios. Apple verification passed 65 unit/layout tests, all 12 UI scenarios on both iPhone and iPad, and a macOS build and manual check.

Requires Android 9 or newer. Version code: 15. Signed with the existing release key; updating preserves books, positions, and settings.
