# Still 0.1.18

- Discover public-domain ebooks beside file import in the native library.
- Search Project Gutenberg by title or author, filter by language, browse pages, and view covers and book details.
- Download individual EPUBs with progress and cancellation; keep source files, covers, metadata, and reading progress offline in the existing library.
- Connect additional OPDS catalogs, including Standard Ebooks with your own authorized access. Credentials remain in memory for the session.
- Prevent duplicate EPUB imports while preserving the existing chapter navigation, reading modes, text repair, and portable backups.

The release retains the full-width reader improvements from 0.1.17. Gutendex availability can vary; failed requests can be retried. OPDS borrowing, purchases, DRM fulfillment, and OAuth are not supported.

Android package: `com.stillreader.app`, version code **19**. Signed with the existing Still release key so it updates earlier release installations.
