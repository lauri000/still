# Still 0.1.16

Still now imports EPUB books on Android, iPhone, iPad, and Mac.

- Read DRM-free, reflowable EPUB 2 and EPUB 3 books in single-line or scrolling passage mode.
- Navigate chapters using the book's table of contents, with exact positions and native heading cues.
- Prepare reading data once during import and retain the original EPUB for reprocessing. EPUB books support text corrections, reading-start choices, backups, and position-preserving view changes.
- Preserve explicit EPUB line breaks in the passage view, and restore a section's text, headings, and chapter positions together.
- Prepare text edits in the background and avoid repeated scans of long sections, keeping editing and opening the reader responsive.

EPUB import extracts text and structure; images, publisher styling, fixed-layout books, and DRM-protected books are not supported.

**After updating:** PDF books already prepared in 0.1.15 do not need reprocessing. New EPUB backups use book format version 3 and require this version of Still or newer. EPUB books imported with an earlier development build need **Reprocess book** to prepare the updated line-break data.

Verified with 59 Android unit tests, 85 Apple unit/layout tests, five focused Android device scenarios, three iPhone UI scenarios, matching Android/Apple output for seven EPUB fixtures, and a macOS build. The signed Android release also runs core unit tests and release lint and verifies 16 KB alignment. EPUB test books are downloaded from documented sources and are not stored in Git.

Requires Android 9 or newer. Version code: 17. Signed with the existing release key; updating preserves books, positions, and settings.
