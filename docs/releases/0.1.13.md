# Still 0.1.13

Less rendering overhead when scrolling multiline text on Android.

- Simplifies word touch targets and avoids rebuilding unaffected rows as your reading position changes.
- Preserves normal scroll momentum and exact-word taps into single-line view.
- Keeps mode switching, rotation, saved positions, and accessibility word actions working.

Verified with 39 unit tests and 26 Android UI scenarios. Large-book emulator profiling showed fewer long frame stalls; physical-device performance may vary.

Requires Android 9 or newer. Version code: 14. Signed with the existing release key; updating preserves books, positions, and settings.
