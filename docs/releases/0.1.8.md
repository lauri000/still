# Still 0.1.8

Read in stable rows with the new scrolling passage view on Android, iPhone, iPad, and Mac.

- Multiline text scrolls vertically while the active highlight advances from word to word within each row.
- Exact word timing and natural pauses guide the scroll, and releasing the hold gesture freezes your place.
- Natural word spacing and a passage-wide text size control keep the layout steady. The current word is marked by text color, with an optional red focus letter and no background box.
- Single-line reading, hold-to-read, speed gestures, and the compact controls retain their existing behavior.
- Includes the local PDF text-repair improvements from 0.1.7.

Requires Android 9 or newer. The universal APK includes ARM64, ARMv7, x86, and x86_64 libraries. Version code: 9.
Signed with the same Android release key as previous releases; updating preserves your books, reading positions, and settings.

The APK, SHA256SUMS, source commit manifest, and public signing certificate are attached to this release.
