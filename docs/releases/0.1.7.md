# Still 0.1.7

Smoother reading from PDFs, with improved word spacing and line-break handling on Android, iPhone, iPad, and Mac.

- Repair split words, fused words, broken ligatures, and words wrapped across lines or pages while preserving recognized hyphenated compounds.
- Clean up new PDF imports entirely on your device, without OCR, an AI model, or a network connection.
- Choose **Improve text** from an existing book's menu. Manual corrections and excluded pages are preserved, and saved reading positions move with their words.
- Undo a text improvement during the current session, or restore a page's original extraction in the text editor.

Evaluated on 846 pages across three books. Android emulator imports took approximately 2.7–3.4 seconds per book. Unusual layouts, footnotes, and ambiguous hyphens can still need manual corrections.

Requires Android 9 or newer. The universal APK includes ARM64, ARMv7, x86, and x86_64 libraries. Version code: 8.
Signed with the same Android release key as previous releases; updating preserves your books, reading positions, and settings.

The APK, SHA256SUMS, source commit manifest, and public signing certificate are attached to this release. Download all four assets into one directory and run the SHA-256 verification command shown in the publishing guide.
