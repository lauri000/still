# Still 0.1.10

Simpler, faster multiline reading for large books.

- Plain scrolling text without highlighted words or letters.
- Reading options apply only to single-line mode; multiline keeps the same hold-to-read, speed controls, and saved position.
- Nearby text is laid out on demand, removing the whole-book work behind slow view switches and the reported Natural pauses failure.

Requires Android 9 or newer. Version code: 11. Signed with the existing release key; updating preserves books, positions, and settings.
