# Still 0.1.3

A calmer passage view with equal-sized words and aligned rows.

- Keep the active word dark and centered, with surrounding words in the same size and a muted color.
- Use evenly spaced, justified rows so full lines align to the same edges. Short paragraph endings keep normal spacing.
- Keep the larger active word in single-line mode, with the same swiping, word selection, focus-letter option, and hold-to-read controls.
- Use the improved passage layout automatically, without another setting.

Requires Android 9 or newer. This universal APK includes ARM64, ARMv7, x86, and x86_64 libraries.
Version code: 4. Signed with the same Android release key as previous releases;
updating preserves your books, reading positions, and settings.

The APK, SHA256SUMS, source commit manifest, and public signing certificate are
attached to this release. Download all four assets into one directory and run
`shasum -a 256 -c SHA256SUMS` to verify their checksums.
