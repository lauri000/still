# Still 0.1.22

- Show EPUB chapter names and overall percentage read in the reader and library.
- Show each chapter’s position in the book in Contents, and add **Go to progress** for navigation by percentage, including books without a chapter list.
- Hide numbered EPUB source sections throughout reading and book tools. Text tools describe the chapters in each editable text unit.
- Calculate progress from retained words, respecting the chosen beginning and excluded text. Several chapters within one EPUB file have their own exact destinations.

Book storage, chapter anchors, corrections, backups, and saved positions are unchanged. No reimport or migration is needed. PDF page navigation remains available.
