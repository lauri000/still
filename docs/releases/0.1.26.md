# Still 0.1.26

- Remove **Pause at unchecked text/pages** from reading options on Android, iPad/iPhone, and macOS, along with its saved preference and playback checks.
- Read unchecked text whenever playback starts, and skip pages without text. Reading no longer opens a review prompt or saves a blocked-page position.
- Resume older positions on blank pages at readable text. Seeking blank pages selects the next readable word, or the last word when no later text exists.
- Keep optional text corrections and review labels in the book tools. Playback does not change review status, original files, or saved corrections.

Validation: 88 Android unit tests and 100 Apple unit tests passed (five optional corpus tests skipped), along with three Android and two iPad reader UI tests. Coverage includes unchecked and blank-page playback, saved positions, scrubbing, replay, and switching reading modes. The release build runs Android unit tests and release lint, verifies APK signing and alignment, and records the source commit and checksums. The macOS build and local publishing-tool tests are also checked.

Requires Android 9 or newer. Android package: `com.stillreader.app`, version code **27**. Signed with the existing Still release key so it updates earlier release installations while preserving the library and settings. No re-import is needed.

The APK, SHA256SUMS, source commit manifest, and public signing certificate are attached to this release. Zapstore publication uses the local hidden nsec prompt.
