# Still 0.1.4

Choose how prominent the active word is, with optional animated scrolling.

- Adjust **Active word size** from **100% to 300%** with a percentage slider in Reading options. The same saved setting applies to single-line and passage views.
- Start at 100% to match surrounding text, or enlarge the active word while keeping it centered. Long words still shrink to fit.
- Turn on **Animated scrolling** to move surrounding words during playback in either view. It is off by default and respects reduced-motion settings.
- Pause or navigate manually to settle the text immediately. Changing size or switching views keeps your reading position.
- Keep justified passage rows, muted surrounding text, focus-letter highlighting, and the existing hold-to-read and speed gestures.

Requires Android 9 or newer. This universal APK includes ARM64, ARMv7, x86, and x86_64 libraries.
Version code: 5. Signed with the same Android release key as previous releases;
updating preserves your books, reading positions, and settings.

The APK, SHA256SUMS, source commit manifest, and public signing certificate are
attached to this release. Download all four assets into one directory and run
`shasum -a 256 -c SHA256SUMS` to verify their checksums.
