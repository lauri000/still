# Still 0.1.24

- Fix premature timeouts when searching Project Gutenberg. Fresh Gutendex searches can take 30–40 seconds to respond; Still previously stopped waiting after 20 seconds. Each search now has a bounded 60-second budget, with a matching network read timeout.
- Explain when the catalog is responding slowly after eight seconds, while keeping Cancel available. Requests are not automatically restarted, and canceled or replaced requests cannot overwrite newer results.
- Trim outer whitespace and lowercase case-insensitive search URLs so equivalent queries such as `Anarchy` and `anarchy` reuse cached results. Keep the typed query, language filter, and pagination behavior intact.

Reproduced using `anarchy`: a cached request returned in 0.24 seconds, while fresh equivalent and English-filtered requests took 29.97 and 39.91 seconds and returned HTTP 200. Live Android searches with both All languages and English returned 10 downloadable books after the fix. Gutendex can still be slow or unavailable; this release avoids rejecting valid slow responses but cannot remove provider latency.

Validation: 83 Android unit tests (3 optional corpus tests skipped), 105 Apple unit/integration tests (2 optional corpus tests skipped), five Android device catalog tests including live searches, EPUB download/import and duplicate prevention, cancellation, Network permission handling, and backup. New regressions cover a successful 40-second response, bounded timeout, cancellation, and equivalent-query caching. Android lint and the macOS build pass. The signed release build also runs Android unit tests and release lint. Physical-phone testing remains outstanding.

Built and published from `main`. Requires Android 9 or newer. Android package: `com.stillreader.app`, version code **25**. Signed with the existing Still release key so it updates earlier release installations while preserving the library and settings.

The APK, SHA256SUMS, source commit manifest, and public signing certificate are attached to this release.
